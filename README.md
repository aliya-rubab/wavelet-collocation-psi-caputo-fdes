# MATLAB Implementation of a Wavelet Collocation Method for ψ-Caputo Fractional Differential Equations

## Overview

This repository provides a MATLAB implementation of a wavelet collocation method for solving linear and nonlinear ψ-Caputo fractional differential equations.

The numerical method is based on ψ-Gegenbauer wavelets, which are constructed from classical Gegenbauer wavelets. The implementation includes the ψ-fractional integration operational matrix for ψ-Gegenbauer wavelets and demonstrates its application through numerical examples and error analysis.
## Features

- MATLAB implementation of a wavelet collocation method based on ψ-Gegenbauer wavelets.
- Construction of ψ-Gegenbauer wavelets from classical Gegenbauer wavelets.
- ψ-fractional integration operational matrix for ψ-Gegenbauer wavelets.
- Numerical solution of linear and nonlinear ψ-Caputo fractional differential equations.
- Numerical examples with error analysis.
