# MATLAB Implementation of a Wavelet Collocation Method for ψ-Caputo Fractional Differential Equations

## Overview

This repository provides a MATLAB implementation of a wavelet collocation method for solving linear and nonlinear ψ-Caputo fractional differential equations. The numerical scheme employs Gegenbauer wavelets as basis functions and operational matrices to approximate the solution.

The repository includes the implementation of a ψ-fractional integration operational matrix for Gegenbauer wavelets, along with numerical examples and error analysis.
